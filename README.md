# 暗記カード

個人用の間隔反復（スペースドリピティション）暗記カードアプリです。

[https://shots5921.github.io/anki/](https://shots5921.github.io/anki/) で開きます。

カードデータはブラウザの localStorage にのみ保存されます。

## 画像から追加

カード一覧の「画像から追加」でスクリーンショットや写真を選ぶと、ブラウザ内の OCR（Tesseract.js、日本語と英語）で文字を読み取ります。画像はサーバへ送らず、初回だけ言語データを CDN から取得します。読み取った文字を選んで「単語にする」「意味にする」を押し、「カードを追加」でいつものカードと同じように登録できます。文字は追加後も残るので、1枚の画像から何枚でも作れます。行が「単語,意味」の形なら「まとめて追加へ送る」も使えます。
