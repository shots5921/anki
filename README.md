# 暗記カード

個人用の間隔反復（スペースドリピティション）暗記カードアプリです。

[https://shots5921.github.io/anki/](https://shots5921.github.io/anki/) で開きます。

カードデータはブラウザの localStorage にのみ保存されます。

## 画像から追加

カード一覧の「画像から追加」で、画像を選ぶ、読み取り、結果の順に進みます。読み取りはブラウザ内の OCR（Tesseract.js、日本語と英語）で、画像はサーバへ送りません。初回だけ言語データを CDN から取得します。結果では行をタップして選び、「単語にする」「意味にする」で欄に入れます。文字を直すこともできます。「カードを追加」はいつものカードと同じです。文字は残るので、1枚の画像から何枚でも作れます。「まとめて追加へ送る」で一括追加にも渡せます。
